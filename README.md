# 锦绣长卷

2026 年“零杯”网页设计大赛参赛作品 · 主题二「匠心传承，非遗焕新」· 创意网站 · 零组

一针一线，绣出千年。全站以“织绣”为单一主角，用一条缓缓展开的数字长卷，讲述一根丝线穿越千年的故事，并融入武汉大学的珞珈山、樱花与校训元素。

## 成员

- 陈金鑫 · 电子信息学院 · 大一

## 页面

- 首页「锦绣长卷」：叙事长卷（蚕桑起源 / 四大名绣 / 常见针法 / 织绣简史 / 丝线之色 / 纹样寓意 / 珞珈 / 匠心故事 / 薪火相传）
- 互动页「亲手一试」：穿针 → 配色 → 绣樱花 → 纹样翻牌小游戏
- 关于页
