锦绣长卷 · 立意说明

本作品以「匠心传承，非遗焕新」为主题，选取中国织绣技艺为切口，尝试用一条缓缓展开的“数字长卷”，讲述一根丝线穿越千年的故事；并融入武汉大学的珞珈山、樱花与校训元素，让非遗传承与校园记忆同织一线。全站所有视觉纹样与插画均为手写 SVG / CSS / Canvas 绘制，文字内容原创，不引用任何受版权保护的图片与文案。

为什么是“长卷”

织绣的本质，是一针一线在时间里的累积；长卷的展开，也是一寸一寸的铺陈。二者同构——于是我们让一根丝线贯穿全页，随滚动前进，把“刺绣”这个过程本身变成导航与阅读的线索。

技术说明

全站为纯 HTML / CSS / JavaScript（ES Modules），无构建、无外部依赖、无预设样式库。动效与互动均为手写实现，可在 Chrome 129 及现代浏览器中直接打开运行，并针对 1920 / 1440 / 720 及移动端做了响应式适配。

致谢

感谢四大名绣世世代代的绣工们，让一门古老技艺在针尖上延续至今。本作品内容为文学化表达，旨在传播非遗之美。
